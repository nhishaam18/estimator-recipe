# Script pipeline and visual model boundary

Estimator runs the trusted flow command directly; only Visual Analysis interprets screenshots. No Developer execution agent. Scripts reserve at most two distinct packets. Each may be an overlapping tile from the same screenshot or a tile from another page, with a unique per-attempt draft path.

The saved reservation/flow receipt is dispatch intent before model launch. Estimator passes only runDir/requestId/promptFile/image/resultFile and omits runId/history/background. Dispatch the two workers in the same assistant tool-call batch and wait for automatic completion; serial dispatch is allowed when parallel calls are unavailable. Replayed/reused reservations require reconciliation, never duplicate dispatch. Native tools are supplied by Kajoo; workers cannot delegate.

Save actual platform job IDs/statuses in the exact outcomes envelope in [flow contract](job-contract.md), then invoke flow settle-batch directly. Scripts validate/import completed drafts serially, retain successful siblings and reserve next work. Workers never edit manifests, merged detections, annotations or Build Lists. A model-ready sentence is not platform completion. Unknown/running holds slots; failed or empty imports stop for diagnosis.

After diagnosis explicitly reserve one transient retry or at most two corrections per request with the documented batch command. Never overwrite originals, overlap active work or clear circuit breakers automatically. Real consent/lazy-loading failures use supported one-route recovery only after batch reconciliation.

Primary source-tile inspection, deterministic validation and focused corrections remain. No paired raw/annotated-region pass. Geometry, ownership, cards/slider items/hero composites, CTA rules, DOM refinement, unique-family counting and complete field/style reports remain unchanged. Unresolved findings stay provisional.
