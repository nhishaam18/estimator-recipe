# Small context, script-controlled work

Estimator calls one packaged flow command per transition. Scripts construct jobs, hold locks, execute stages, validate/import results, reserve packets and save receipts/checkpoints. Do not launch a Developer agent or manually reproduce pipeline algorithms. Keep only runtime/bootstrap/verification paths, approved sample, plan/run/checkpoint, active batch/request/job IDs, estimate progress and blockers in durable coordination state. Read that small state after a summary; never reconstruct it from full history.

Save complete Firecrawl output immediately and reuse it. Prefer a real tool-provided result file; inline-only output still requires saving once and has no implicit file API. Never repeat Map/capture or resample because context was cleared. Large evidence remains in files; the coordination loop does not read screenshots, DOM/styles, detections or complete reports. Visual Analysis receives only its assigned packet. For estimates, `estimate-next` returns one assigned packet; `estimate-record` saves its fragment and completed keys. Resume from `estimation/progress.json` through `estimate-next`, not chat history.

Estimator retains its 24-message summarization trigger, eight messages and 16K summary-input cap; tool clearing triggers at 24K and retains six messages. Visual Analysis is unchanged. These are retention controls, not provider token ceilings. Script checkpoints remain authoritative when summaries are incomplete. Fixed system/tool overhead and result checks remain; removing Developer launches reduces boundaries rather than claiming they disappear.

Run one foreground command; no background shell loops, polling or duplicate processes. Script reservations cap fan-out at two; middleware maxConcurrency alone does not enforce it. Save verified actual outcomes only. Replayed reservations require reconciliation. Blocked/unknown/failed work stops automatic advancement. One supported recovery, bounded visual corrections and preserved gaps replace open-ended repair.

Keep source hashes, resolution, overlap, Section/Inner boundaries, cards, CTAs, owned fields, typography/styles and unique-family counting. No automatic paired-region pass. Benchmark identical frozen inputs, models, cache conditions and completed coverage across ALL agents. Deterministic tests cannot certify live token savings.

For an oversized read, do not repeat it or read conversation-history JSONL. Use node <runtime>/scripts/cest.mjs read-evidence --file <named checkpoint/error file> --pointer /neededField --limit 4000. Omit pointer for text; use returned nextOffset only when more of that specific evidence is necessary. Output is character-bounded even for one long JSON line. Never page through full history or bulk raw evidence. Recover from saved checkpoint/packet paths.
