# Quality and limits

Quality reports explain failed capture, obstructing consent overlays, missing assets, uncertain component boundaries, missing fonts/styles and unobserved interaction states. For any identifiable component, a missing image, text or icon is a nonblocking appearance gap. Preserve its boundary and avoid inventing missing fields. A corrupt/unreadable tile or overlay obscuring the component blocks only the affected page until corrected.

Scripts validate tile source hashes, request identity, coordinate scale and geometry before importing results. Finished tile files are retained on targeted correction. The next screenshot is not prepared until all jobs for the current screenshot are settled. Exact repeated image-and-DOM tiles can reuse a classification; weaker matches go to the visual agent.

Coverage counts refer to the user-selected sample and representative desktop captures. Deferred URLs, failed scans, missing interactions and mobile layouts are not claimed covered. Effort hours are provisional and model billing is external to the script.
