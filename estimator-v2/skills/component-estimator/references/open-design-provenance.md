# Visual evidence provenance

The recipe applies source-first website analysis: saved DOM structure, rectangles, computed styles, font/asset information and screenshots are evidence. Scripts collect and report measured CSS, typography, spacing and colors. Visual Analysis supplies boundaries and component-owned fields that pixels support; it does not invent exact CSS values from images.

Page-level DOM comparison avoids unnecessary screenshots. Structural tile seams and small overlaps preserve readable details. Exact image-and-rectangle signatures may reuse a prior classification; unmatched regions require visual inspection. The report keeps evidence paths and uncertainty so a later CMS developer can implement the fields and composition under the selected CMS guidelines.
